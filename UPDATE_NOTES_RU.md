# HUNTARES TOOL — обновление интерфейса

- Главный экран: иконка, карточки PAK/LUA, настройки, лицензии.
- Выбор акцентного цвета: белый, фиолетовый, голубой, бирюзовый, красный, золотой.
- Сохранены Python-модули и рабочие сценарии из загруженного пользователем проекта.
- Экран лицензий описывает будущие универсальные и HWID ключи. **Сервер и выдача/проверка ключей не реализованы.**
- Функции PAK/LUA не тестировались на реальных игровых файлах в этой версии.

## Обновление в Termux

Распаковать содержимое архива в корень `~/Tool-huntares` (не во вложенную папку):

```sh
cd ~/Tool-huntares
unzip -o ~/storage/downloads/HUNTARES_TOOL_UI_UPDATE.zip
# Если ZIP содержит Tool-huntares-main/, скопируйте его содержимое в корень репозитория.
git add -A
git commit -m "HUNTARES TOOL refreshed UI"
git push origin main
```

После успешной сборки GitHub Actions скачать артефакт `HUNTARES-TOOL-debug-APK`.
