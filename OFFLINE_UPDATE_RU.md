HUNTARES TOOL — OFFLINE 1.2

Это исходники, не готовый APK.
В этой версии проверка лицензий выполняется локально, без Cloudflare/сервера.
Администратор вводит согласованный ключ (без точки в конце).
Ключи и данные о них хранятся локально.

УСТАНОВКА:
1. Загрузите содержимое папки huntares_release в корень репозитория Tool-huntares.
2. Запустите GitHub Actions > Build Android APK.
3. Скачайте артефакт HUNTARES-TOOL-OFFLINE-APK.
4. Установите APK. Если Android не предлагает обновление, сохраните важные данные, удалите старое приложение и установите новое. При удалении данные приложения могут исчезнуть.

ПРОВЕРКА:
Экран активации должен показывать 'ОФЛАЙН-ВЕРСИЯ' и не должен показывать настройку сервера.

ПРЕДУПРЕЖДЕНИЕ: Это офлайн-демонстрация лицензирования. В исходниках приложения присутствует закрытый ключ подписи пользовательских лицензий, поэтому нельзя считать их защищёнными от подделки.
