# HUNTARES TOOL APK — исходники Android

**Статус:** проект для сборки и тестирования. APK в этой поставке не скомпилирован. Android/Chaquopy/PAK на реальном устройстве не проверены.

## Файловая схема

При первом запуске нажмите «Разрешить доступ / выбрать папку» и выберите доступную папку, например `Documents` во внутренней памяти. В ней приложение создаст:

```
HUNTARES TOOL/
  LUA TOOL/
    ОРИГИНАЛ ЛУА/
    lua_unpak/
    result_lua/
  PAK TOOL/
    ОРИГИНАЛ ПАК/
    PAK UNPACK/
    PAK REPACK/
```

Файлы исходного Lua положите в `ОРИГИНАЛ ЛУА`, затем нажмите «Расшифровать»; отредактируйте файл из `lua_unpak`, затем «Собрать обратно с изменениями». Результат будет в `result_lua`. Название оригинала должно совпадать с названием редактируемого файла (`.lua` или `.luac`).

Для PAK положите оригинальный `.pak` в `ОРИГИНАЛ ПАК`, выберите режим и нажмите `PAK UNPACK`. Результат в `PAK UNPACK/<имя патча>/`. После редактирования нажмите `PAK REPACK` и выберите тот же оригинал.

**Ограничения:** Lua 5.3 поддерживаемого формата; декомпиляция не всегда точная. PAK-обработчик экспериментальный и не подтверждён на реальном Android. Режим «Полный PAK + Lua» извлекает файлы, но пока **не выполняет автоматическую декомпиляцию Lua внутри PAK**. Режимы Lua/ассеты фильтруют распакованные файлы после извлечения, что требует свободного места. Для больших PAK приложение может упереться в объём памяти/диска. Не заменяйте оригинальные файлы без резервной копии. Не гарантируется совместимость с зашифрованными/подписанными PAK.

## Сборка APK на ПК

Установите Android Studio, Android SDK Platform 35, Android SDK Build Tools, JDK 17, Python 3.11, Gradle 8.10.2. Откройте корень проекта в Android Studio и выберите **Build > Build APK(s)**.

Либо в терминале с установленным SDK и Gradle:

```sh
export ANDROID_HOME="$HOME/Android/Sdk"  # замените на реальный путь к SDK
export JAVA_HOME=/path/to/jdk17          # замените на путь к JDK 17
gradle --no-daemon assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`.

## Сборка без ПК через GitHub Actions

Загрузите **содержимое** ZIP в корень нового репозитория GitHub (включая `.github/workflows/build-apk.yml`), откройте вкладку **Actions**, выберите **Build Android APK → Run workflow**. После успешной сборки скачайте артефакт `HUNTARES-TOOL-debug-APK`. Это автоматическая сборка, **не** публикация исходников; можно использовать приватный репозиторий.

## Распаковка ZIP без создания новой папки

На Termux:

```sh
termux-setup-storage
pkg install unzip -y
cd ~/storage/downloads
unzip -o HUNTARES_TOOL_ANDROID_SOURCE.zip
```

Команда распакует файлы в текущую папку, **без создания дополнительной корневой папки**. Если не хотите смешивать исходники с загрузками, распакуйте в заранее выбранную пустую папку. Команды Git не требуются.
