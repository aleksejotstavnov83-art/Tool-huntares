# HUNTARES TOOL — исходники Android + сервер лицензий

## В ZIP
- Android Java + Chaquopy проект для сборки APK через GitHub Actions (`.github/workflows/build-apk.yml`).
- `license_server/server.py`: Python 3 сервер лицензирования на SQLite.
- Черно-белый UI, активация, 2×2 инструменты, настройки без цветов, скрытая админ-панель.
- Кнопка Telegram `@haunter_extaze` на экране активации.

## Подготовка сервера (обязательно)
На сервере с Python 3.9+:
```
cd license_server
export HUNTARES_ADMIN_KEY="$(python3 -c 'import secrets;print(secrets.token_urlsafe(40))')"
echo "$HUNTARES_ADMIN_KEY" # СОХРАНИТЕ В СЕКРЕТНОМ МЕСТЕ
python3 server.py
```
Сервер слушает 127.0.0.1:8765. Для Android нужен домен и HTTPS reverse proxy (например Caddy или nginx), направленный на этот порт. Не открывайте HTTP без TLS. Для постоянной работы настройте systemd и сохраните HUNTARES_ADMIN_KEY в защищенном env-файле. Не помещайте ключ администратора в GitHub или APK.

## Android
1. Загрузите файлы проекта в GitHub репозиторий.
2. Запустите Actions → Build APK; скачайте debug APK из Artifacts.
3. Установите APK, нажмите «Настроить адрес сервера», введите HTTPS URL вашего сервера.
4. Введите сохранённый секретный админ-ключ — появится админ-панель.
5. Создайте HWID или универсальный ключ, передайте пользователю. У пользователя админ-панели нет.

## Важные ограничения
- **APK не собран в этой среде:** ZIP содержит исходный Android-проект.
- Лицензии реально работают **только после запуска и настройки вашего сервера**. Без сервера вход невозможен.
- «HWID» здесь — случайный идентификатор установки приложения. Он сбрасывается при удалении данных/переустановке, это НЕ аппаратный идентификатор телефона. Модель телефона берется из Android Build, без IMEI.
- Проверка лицензии выполняется при входе в приложение. Для мгновенного отзыва уже открытой сессии нужны дополнительные периодические проверки.
- Универсальные ключи позволяют неограниченные активации, но сервер записывает устройства.
- Длительность ключа считается с момента создания.
- Android UI использует dp, прокрутку, весовые колонки и масштабируемую иконку; на разных экранах нужна проверка реальным устройством.
- PAK/LUA поддержка зависит от формата входных файлов. Исходные Python обработчики включены как в предыдущем проекте.
