# HUNTARES TOOL — обновление офлайн-входа

Администратор вводит ранее выбранный ключ в обычное поле активации. Его текст **не записан в Java-исходник**: проверяется SHA-256 хеш. Включена R8-минификация и обфускация для debug/release.

## Установка через Termux

1. Скачайте ZIP в Download.
2. Распакуйте архив и перенесите **содержимое** `huntares_release` в корень GitHub-проекта.
3. Выполните git add/commit/push; в GitHub Actions запустится сборка.

## Ограничения безопасности

Хеширование **не защищает** от модификации APK и обхода локальной проверки. Текущая реализация **по-прежнему содержит закрытый RSA-ключ подписи пользовательских лицензий внутри APK**; любой, кто его извлечёт, сможет создавать лицензии. Это демонстрационная офлайн-система, не защищённая коммерческая система. Для устойчивой защиты ключ подписи должен находиться только на доверенном устройстве/сервере, а клиент — хранить лишь публичный ключ.

R8 может требовать дополнительных keep-правил при обновлении библиотек. APK не собран и не проверен на телефоне; сборка через GitHub Actions.
